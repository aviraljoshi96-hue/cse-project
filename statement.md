
# Problem Statement

Develop a Python program to calculate an employee's salary and generate a salary slip.

The program should accept the employee's ID, name, and basic salary as input. It should calculate the employee's HRA, DA, transport allowance, gross salary, provident fund, professional tax, total deductions, and net salary.

The calculated information should then be displayed in the form of a simple salary slip.

## Objectives

- To store employee information using a Python dictionary.
- To calculate different salary components using arithmetic operations.
- To calculate gross salary and total deductions.
- To calculate the final net salary.
- To display the employee's salary details in a clear format.

## Input

- Employee ID
- Employee Name
- Basic Salary

## Processing

1. Calculate HRA as 20% of the basic salary.
2. Calculate DA as 10% of the basic salary.
3. Add a fixed transport allowance of ₹2000.
4. Calculate gross salary.
5. Calculate provident fund as 12% of gross salary.
6. Add professional tax of ₹200.
7. Calculate total deductions.
8. Calculate net salary.

## Output

The program displays an employee salary slip containing:

- Employee ID
- Employee Name
- Basic Salary
- HRA
- DA
- Transport Allowance
- Gross Salary
- Provident Fund
- Professional Tax
- Total Deductions
- Net Salary
